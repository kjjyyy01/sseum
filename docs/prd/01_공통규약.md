## 저장 방식 결정 (2026-09-27)
- 데이터는 **브라우저 localStorage** 1곳에만 저장한다. 서버·DB·인증 없음.
- 규모를 키울 때 DB(Supabase)로 옮긴다. 옮기기 쉽도록 저장소 함수명은 v1.0.0 PRD-API명세의 Server Action 이름과 같게 둔다(`lib/store.ts`). 전환 시 이 파일 안쪽만 교체한다.
- 알려진 한계: 기기·브라우저 간 동기화 없음, 브라우저 데이터 삭제 시 유실, **iOS Safari는 7일 미방문 시 localStorage 삭제(ITP) — 홈 화면에 추가한 웹앱은 예외**. 대응은 설정의 JSON 백업(PRD-SCR-007).

## 값 표준
- 날짜: ISO 8601 (`YYYY-MM-DD`), 월: `YYYY-MM`
- 시간대: **Asia/Seoul 고정**(단일 시장). 날짜 경계 계산은 `lib/store.ts`의 `todayStr()` 기준
- 입력 시각: `createdAt` = epoch ms(`Date.now()`). 최근 사용순·최근 입력 정렬에만 쓴다
- 통화: KRW / 금액: 정수 원 단위(소수 없음)
- 주 시작: 월요일

| 유형 | 규칙 |
| ---- | ---- |
| 사용자 화면 | 전부 Client Component가 `useDb()`로 localStorage를 읽어 그린다. 서버는 데이터를 모르므로 서버 렌더·하이드레이션 첫 프레임은 빈 화면(또는 스켈레톤) |

| SSG 공개 페이지 | 없음 (`/login`·`/terms`·`/privacy` 폐기) |
| ISR | 미사용 |
| 쓰기 | `lib/store.ts` 함수 단일 경로. 컴포넌트에서 localStorage 직접 접근 금지 |
| 갱신 | 저장 성공 → 구독자 알림 → 구독 중인 화면 재렌더. 다른 탭은 `storage` 이벤트로 동기화 |
