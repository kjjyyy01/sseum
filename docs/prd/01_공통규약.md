## 값 표준
- 날짜: ISO 8601 (`YYYY-MM-DD`), 월: `YYYY-MM`
- 시간대: 사용자 로컬 = **Asia/Seoul 고정**(단일 시장). DB timestamptz는 UTC 저장, 날짜 경계 계산은 앱 레이어에서 Asia/Seoul
- 통화: KRW / 금액: 정수 원 단위(소수 없음)
- 주 시작: 월요일
## 렌더링 규약 (Next.js App Router)
| 유형 | 규칙 |
| ---- | ---- |
| SSG | 공개 페이지(`/login`, `/terms`, `/privacy`)만. `generateMetadata` + OG 담당 |
| SSR(동적) | 인증 화면 전부. Server Component가 Supabase 서버 클라이언트(쿠키)로 데이터 로드. `cookies()` 사용으로 자동 동적 |
| CSR | 상호작용 리프(폼·토글·칩·GSAP 대상)만 `"use client"`. 데이터 fetch는 CSR에서 하지 않는다(Server Action 응답으로 갱신) |
| ISR | 미사용 (MVP ADR-005). 사용자별 데이터는 공유 캐시 불가 |
| 쓰기 | Server Action 단일 경로. REST 표기(`/api/v1/...`)는 계약 명세이며 Route Handler로 노출은 선택 |
| 갱신 | Server Action 성공 후 `revalidatePath` 해당 라우트 |

## 타인 리소스 응답 규약
타인 리소스 접근은 RLS로 행이 보이지 않으므로 **404 `ERR-COMMON-003`** 로 응답한다(존재 여부 비노출, IDOR 방지). spec 템플릿의 "403"은 이 프로젝트에서 404로 대체 — QA 게이트 AC-5는 404를 기대값으로 한다.
