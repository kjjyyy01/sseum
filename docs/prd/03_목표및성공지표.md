# 목표 및 성공지표 (MVP §4 승계)

| ID | 가설 | 지표 | 목표 | 측정 시점 | 실패 시 행동 | 계측 이벤트 |
| -- | ---- | ---- | ---- | ---- | ---- | ---- |
| H-01 | 입력 직후 피드백이 "기록만 하고 안 본다"를 깬다 | 사용자별 주간 입력일 수 (distinct date) | 활성 사용자 중앙값 ≥ 4일/주, 2주 연속 | 런칭 +14일 | Pivot(피드백 재설계). 표본: 가입 < 5명이면 보류·2주 연장 | EVT-TXN-001, EVT-FB-001, EVT-SESS-001 |
| H-02 | 감시 대상 + 즉시 피드백이 반복 지출 횟수를 줄인다 | 감시 대상 카테고리 주간 건수, 2주차 vs 1주차 | 활성 사용자 50% 이상 감소 | 런칭 +14일 | 피드백 문구·위치 A/B 1회 후 재판정 | EVT-TXN-001(category_is_watched), EVT-CAT-001 |
| H-03 | 입력이 3탭·10초 안에 끝나야 지속된다 | duration_ms p50, tap_count p50 | ≤ 10,000ms, ≤ 3탭 | 런칭 +14일 | 입력 마찰 제거(프리셋 확대) | EVT-TXN-001 |

**킬 크라이테리아(PLAN §1):** 런칭 2주 후 H-01 미달 → Pivot. 표본 조건 미달 시 판정 보류. (사용자 확정 대기: MVP OQ-004)
