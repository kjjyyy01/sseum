# 목표 및 성공지표 (MVP §4 승계)

| ID | 가설 | 지표 | 목표 | 측정 시점 | 실패 시 행동 | 산출 근거 |
| -- | ---- | ---- | ---- | ---- | ---- | ---- |
| H-01 | 입력 직후 피드백이 "기록만 하고 안 본다"를 깬다 | 주간 입력일 수 (distinct date) | 본인 ≥ 4일/주, 2주 연속 | 사용 시작 +14일 | Pivot(피드백 재설계) | 저장 데이터 `txns.date` (PRD-분석및추적) |
| H-02 | 감시 대상 + 즉시 피드백이 반복 지출 횟수를 줄인다 | 감시 대상 카테고리 주간 건수, 2주차 vs 1주차 | 감소 | 사용 시작 +14일 | 피드백 문구·위치 바꿔 2주 재판정 | 저장 데이터 `countThisWeek` 추이 |
| H-03 | 입력이 3탭·10초 안에 끝나야 지속된다 | 체감 (계측 없음) | ≤ 10초, ≤ 3탭 | 사용 시작 +14일 | 입력 마찰 제거(프리셋 확대) | 측정 안 함 — 필요 시 로컬 기록 추가 |

**킬 크라이테리아(PLAN §1):** 사용 2주 후 H-01 미달 → Pivot. 1인용이라 표본은 본인 1명(OQ-004 해소, 2026-09-27).
