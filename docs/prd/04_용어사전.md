# 용어사전 (MVP §19 승계)

| 용어 | 정의 | 코드 식별자 | 쓰지 말 것 |
| ---- | ---- | ---- | ---- |
| 지출 | 사용자가 기록한 1건의 소비 | `transaction` | 거래(수입 뉘앙스) |
| 감시 대상 | 조절하려고 지정한 카테고리 | `categories.is_watched` | 조절 대상·관심 카테고리 |
| 피드백 | 저장 직후 표시되는 반복 패턴 한 줄 | `feedback` | 알림·리포트 |
| 프리셋 | 최근 30일 거래에서 파생된 (카테고리, 금액) 원탭 조합 | `preset` | 즐겨찾기·템플릿 |
| 구독 | 매달 고정 지출 항목. 거래 자동 생성 없음 | `subscription` | 정기 결제 |
| 체크인 | 구독의 월 사용 여부 자기 신고 | `subscription_checkin` | 리뷰·설문 |
| 고정비 | 활성 구독 금액 합계(파생값) | `fixed_cost` | 고정 지출 |
| 전월 동기간 | 전월 1일 ~ 전월 min(오늘 일자, 전월 말일) | `prev_month_to_date` | 지난달 전체 |
