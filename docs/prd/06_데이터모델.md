# 데이터 모델 — localStorage (SSOT)

## 저장 위치
- 키 `sseum:v1` 하나에 전체 데이터를 JSON 1개로 저장한다. 구현: `src/lib/store.ts`.
- 키가 없으면 시드(BR-017)를 메모리에만 만들고, 첫 쓰기 때 저장한다.
- 값이 손상돼 파싱에 실패하면 시드로 보여 주되, 덮어쓰기 전까지 원문은 그대로 둔다.
- ponytail: 키 1개 전체 직렬화 — 거래 수만 건을 넘기면 IndexedDB 또는 DB로 옮긴다.

## 스키마
```ts
type Db = {
  version: 1;                 // 저장 형식 버전 (PRD-마이그레이션)
  categories: Category[];     // 배열 순서 = 표시 순서, "기타"는 항상 끝
  txns: Txn[];
  subs: Subscription[];
  checkins: Checkin[];
};
type Category = { id: string; name: string; watched: boolean; system: boolean; archived: boolean };
type Txn = { id: string; categoryId: string; amount: number; date: "YYYY-MM-DD"; memo: string; createdAt: number };
type Subscription = { id: string; name: string; amount: number; day: number; categoryId: string | null; cancelledAt: "YYYY-MM" | null };
type Checkin = { subscriptionId: string; month: "YYYY-MM"; used: boolean };
```
- id는 `crypto.randomUUID()`.
- `system` = 시드 "기타"만 true(BR-017, 보관 불가).
- `archived` = 보관 상태(BR-014). `cancelledAt` 있음 = 해지 상태.
- 거래 삭제는 **하드 삭제**(배열에서 제거) — 상태 컬럼 없음(BR-003).

## 제약 (강제 지점 = 화면 폼 검증, 저장소는 입력을 신뢰)
| 대상 | 제약 | 규칙 |
| ---- | ---- | ---- |
| Txn.amount | 1 ~ 100,000,000 정수 | BR-001 |
| Txn.date | 오늘(Asia/Seoul) 이하 | BR-002 |
| Txn.memo | trim 후 ≤ 100자, 빈 값은 `""` | BR-016 (저장소가 trim) |
| Category.name | trim 후 1~20자, 대소문자 무시 유일(보관 포함) | BR-009 |
| 감시 대상 | 보관 안 된 것 중 최대 5개 | BR-004 |
| 보관 | 보관 시 `watched=false` 강제 | BR-014 (저장소가 강제) |
| Subscription.day | 1~28 | BR-015 |
| Subscription.name | trim 후 1~30자 | ERR-SUB-004 |
| Checkin | (subscriptionId, month)당 1개 — 다시 답하면 덮어씀 | BR-008 (저장소가 강제) |

## 시드 (첫 실행, BR-017)
`categories` 7개: 식비 · 배달 · 술/여가 · 구독 · 교통 · 생활 · 기타(system=true). 감시 대상 기본값 없음.

## 파기
| 대상 | 방법 |
| ---- | ---- |
| 전체 | 설정 "모든 데이터 지우기"(BR-012) → 키 삭제 → 다음 읽기에서 시드로 재시작 |
| 거래 1건 | 내역 편집에서 삭제(하드 삭제) |
| 브라우저 측 | 사용자가 사이트 데이터를 지우거나 iOS ITP(7일 미방문)가 지우면 유실 — 백업 파일로 복원 |

## 백업
- 내보내기: `exportJson()` → `sseum-backup-YYYY-MM-DD.json`(Db 그대로, 들여쓰기 2).
- 가져오기: `importJson(text)` — `version === 1`이고 배열 4개가 있을 때만 **통째로 교체**. 병합 없음.

## DB 전환 매핑 (v1.0.0 스키마 ↔ 현재)
| localStorage | v1.0.0 테이블.컬럼 |
| ---- | ---- |
| Category.watched / system / archived | categories.is_watched / is_system / status(ARCHIVED) |
| Txn.date / createdAt | transactions.spent_at / created_at |
| Subscription.day / cancelledAt | subscriptions.billing_day / cancelled_at(+ status CANCELLED) |
| Checkin | subscription_checkins |
| (없음) | user_id·consents·rate_limits·idempotency_key — 전환 시 추가 |
