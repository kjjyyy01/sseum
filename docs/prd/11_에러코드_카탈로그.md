# 에러코드 카탈로그

HTTP 상태 없음(서버 API 없음). 오류는 화면 문구로만 드러난다.

| ERR-ID | 사용자 문구(CPY) | 발생 조건 | field |
| ---- | ---- | ---- | ---- |
| ERR-STORE-001 | CPY-COMMON-001(배너) / CPY-COMMON-009(토스트) | localStorage 쓰기 예외 — 용량 초과·사생활 보호 모드 등 | — |
| ERR-TXN-001 | CPY-INPUT-002 | 금액 범위 위반(BR-001) | amount |
| ERR-TXN-002 | CPY-INPUT-003 | 미래 날짜(BR-002) | date |
| ERR-TXN-004 | CPY-INPUT-006 | 메모 100자 초과(BR-016) | memo |
| ERR-CAT-001 | CPY-CAT-001 | 감시 대상 5개 초과(BR-004) | watched |
| ERR-CAT-002 | CPY-CAT-002 | 이름 중복(BR-009) | name |
| ERR-CAT-003 | CPY-CAT-003 | 이름 길이 위반(BR-009) | name |
| ERR-CAT-005 | CPY-CAT-005 | "기타" 보관 시도(BR-017) | archived |
| ERR-SUB-002 | CPY-SUB-004 | 결제일 범위(BR-015) | day |
| ERR-SUB-004 | CPY-SUB-006 | 구독 이름 길이(1~30) | name |
| ERR-CLEAR-001 | CPY-SET-003 | 지우기 확인어 불일치(BR-012) | confirm |
| ERR-BACKUP-001 | CPY-SET-010 | 가져온 파일이 JSON이 아니거나 형식 불일치(BR-018) | file |

## 폐기 (v1.0.0)
ERR-COMMON-002(오프라인) · ERR-COMMON-003(404·타인 리소스) · ERR-COMMON-004(429) · ERR-TXN-003(이미 삭제됨) · ERR-CAT-004(없는 카테고리) · ERR-SUB-001(체크인 중복 — 덮어쓰기로 대체) · ERR-SUB-003(없는 구독) · ERR-AUTH-001~006 · ERR-ACC-001·002. ERR-COMMON-001(서버 오류)은 ERR-STORE-001로 대체.
