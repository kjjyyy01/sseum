## 3. 모션 규칙 (GSAP) — SSOT

### 3.1 설치·경계
- 패키지: `gsap`, `@gsap/react`. 전 플러그인 무료(2025~). 사용 플러그인: 코어 + `Flip`(M-08·행 이동). ScrollTrigger·SplitText 미사용(랜딩 폐기).
- **Client Component에서만** import. 훅은 `useGSAP(() => {...}, { scope: ref, dependencies })` 고정 — 컨텍스트 자동 cleanup(언마운트 시 트윈 전부 kill). `useEffect` + 수동 gsap 금지.
- 사용자 화면은 전부 Client Component(localStorage)라 서버 트리용 래퍼가 필요 없다.

### 3.2 절대 규칙 (실패 조건)
1. **LCP 요소는 가시 상태로 시작한다.** 각 화면 LCP 후보(SCR-001 첫 WatchCard 또는 Empty 제목 / SCR-003 첫 그룹)는 `opacity:0`·`visibility:hidden`·`y` 오프셋으로 시작 금지. 등장 모션은 LCP 요소를 제외한 주변 요소만.
2. **초기 숨김은 CSS가 아니라 GSAP `from()`으로만.** 데이터가 localStorage에 있어 JS 없이는 화면이 비므로 no-JS 가시성은 목표가 아니다. `gsap.from`이 하이드레이션 직후 실행돼 짧은 FOUC가 생기는 요소는 `data-animate` 속성 + `html.js [data-animate]{opacity:0}` 조합으로만 예외 허용하며, `<html>`에 `js` 클래스를 붙이는 인라인 스크립트는 `<head>` 첫 줄(no-JS면 클래스 없음 → 보임). LCP 요소에는 이 예외도 금지.
3. **`prefers-reduced-motion: reduce`** → `gsap.matchMedia()`로 전 모션을 즉시 완료 상태(`duration: 0` 또는 `gsap.set`)로 대체. 카운트업은 최종 숫자 즉시 표시. 검증은 chrome-devtools 에뮬레이션.
4. **입력 경로에 블로킹 모션 금지.** SCR-002에서 금액 입력·카테고리 탭·저장 사이에 대기시키는 트윈이 없어야 한다. 피드백(M-04)은 저장 응답 **후** 재생되며 사용자는 재생 중에도 즉시 닫거나 이동할 수 있다.
5. **duration 상한** 0.6s. stagger 합계 0.8s 이내. 이징 기본 `power2.out`, 강조 `back.out(1.4)`.
6. **레이아웃 스래싱 금지**: transform·opacity만 애니메이션. width/height/top은 `Flip`으로.
7. `will-change`는 트윈 직전 GSAP가 관리, 수동 지정 금지.
8. 리스트 stagger는 md 이상에서만(`gsap.matchMedia`), base는 단일 페이드(성능·배터리).

### 3.4 파일 구조
```
lib/motion/
  index.ts        ← gsap.registerPlugin(Flip, useGSAP), 공통 이징·duration 상수, prefersReduced 헬퍼
  presets.ts      ← M-01~M-10 함수(각각 (targets, opts) => Tween/Timeline)
```
모션 값(duration·ease·offset)은 `presets.ts`에만 둔다. 화면 컴포넌트에서 숫자 하드코딩 금지.
