# 보안 및 프라이버시 — 로컬 저장

## 인증: 없음
1인용. 이메일·계정·세션·동의 게이트 없음(BR-011·BR-013 폐기). 기기에 접근할 수 있는 사람은 기록을 볼 수 있다 — 통제 수단은 기기 잠금뿐.

## 데이터 인벤토리
| 데이터 | 위치 | 암호화 | 보존 | 파기 |
| ---- | ---- | ---- | ---- | ---- |
| 거래·카테고리·구독·체크인(소비 행위 데이터) | 브라우저 localStorage `sseum:v1` | **없음(평문)** | 사용자가 지울 때까지 | "모든 데이터 지우기"(BR-012) 또는 브라우저 사이트 데이터 삭제 |
| 백업 파일 `sseum-backup-*.json` | 사용자가 저장한 위치 | 없음(평문) | 사용자 관리 | 사용자가 파일 삭제 |

- PII(이메일 등)는 수집하지 않는다. 서버·로그·분석 도구로 전송되는 데이터 없음.

## 위험과 대응
| 위험 | 대응 |
| ---- | ---- |
| XSS로 localStorage 탈취 | 사용자 입력은 React가 이스케이프해 렌더. `dangerouslySetInnerHTML`은 `<html>`에 `js` 클래스를 붙이는 고정 문자열 1곳뿐. 외부 스크립트 없음 |
| 유실(브라우저 삭제·iOS ITP 7일 미방문) | 설정 백업 내보내기. iOS는 홈 화면에 추가해 사용 권장 |
| 잘못된 백업으로 덮어쓰기 | 형식 검사 + 교체 전 확인(BR-018) |
| 공용 기기에서 사용 | 범위 밖 — 개인 기기 전제 |

## 입력 검증
화면 폼에서 BR-001·002·004·009·015·016 검증. 문자열 trim, 길이 상한, 정수 금액. HTML은 저장하지 않는다.

## 보안 헤더 (`next.config` headers — 출시 준비에서 적용)
| 헤더 | 값 |
| ---- | ---- |
| Content-Security-Policy | `default-src 'self'; script-src 'self' 'nonce-{nonce}'; connect-src 'self'; img-src 'self' data: blob:; style-src 'self' 'unsafe-inline'; font-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'` |
| X-Content-Type-Options | `nosniff` |
| Referrer-Policy | `strict-origin-when-cross-origin` |
| Permissions-Policy | `camera=(), microphone=(), geolocation=()` |

## 법적 고지
본인 전용이라 이용약관·개인정보처리방침·만 14세 확인·국외 이전 고지를 두지 않는다. **다른 사람에게 공개하는 시점**에 v1.0.0 방침(git `48ef8f8`)을 복원한다.
