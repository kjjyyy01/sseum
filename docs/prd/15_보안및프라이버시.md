# 보안 및 프라이버시 (MVP §11 [PII] + §15 승계 후 상세화)

## 인증 수명주기 (SSOT)
- 방식: Supabase Auth 이메일 매직링크(OTP 링크). 비밀번호·소셜 없음.
- 세션: Supabase JWT(access 1h) + refresh 토큰. `@supabase/ssr`가 httpOnly·Secure·SameSite=Lax 쿠키에 저장. 미들웨어(`middleware.ts`)가 매 요청 `getUser()`로 갱신.
- 만료·갱신: refresh 토큰 유효 기간 Supabase 기본(무제한 재사용 금지 설정 on). 갱신 실패 → 401 → `/login?next=`.
- 로그아웃: `signOut()` 서버 측 세션 무효화 + 쿠키 삭제.
- 매직링크: 유효 1h, 1회용. `redirectTo`는 `NEXT_PUBLIC_APP_URL/auth/callback`만 허용(Supabase Redirect URL 화이트리스트).
- 동의 게이트(BR-011): 미들웨어가 `consents` 최신 행의 버전이 현재 `TERMS_VERSION`·`PRIVACY_VERSION` 상수와 다르면 `/login?consent=1`.

## PII 인벤토리 (PRD-데이터모델 [PII] 집계)
| 테이블.필드 | 수집 근거 | 보존 기간 | 파기 방법 | 암호화 |
| ---- | ---- | ---- | ---- | ---- |
| auth.users.email | 로그인(계약 이행) | 계정 존속 중 | 계정 삭제 시 `auth.admin.deleteUser` | Supabase 저장 시 암호화(at rest), 전송 TLS |
| consents.* (user_id 연결) | 법적 의무(동의 기록) | 계정 존속 중 | 계정 삭제 시 하드 삭제 | at rest |
| transactions·categories·subscriptions·checkins (user_id 연결 행위 데이터) | 서비스 제공 | 계정 존속 중 | 계정 삭제 시 하드 삭제 | at rest |
| PostHog distinct_id(user id)·이벤트 | 서비스 개선(동의 고지) | 1년(프로젝트 설정) | 계정 삭제 시 person 삭제 API | PostHog 측 |
| Sentry 이벤트(user id, 요청 메타) | 장애 대응 | 90일(플랜 기본) | 자동 | Sentry 측 |
| rate_limits.key(email 해시) | 남용 방지 | window 경과 | lazy 삭제 | SHA-256 해시 |

## 파기 정책
- 회원 탈퇴 시: **즉시** 하드 삭제(순서·안전망은 PRD-데이터모델 파기 정책). 유예 없음(복구 UX 없음, PRD-범위외).
- 백업 내 데이터: Supabase 자동 백업 보존 기간 경과 시 소멸(OQ-003 확인 후 방침에 N일 명시).
- 소프트 삭제(transactions DELETED)는 법적 파기와 무관 — 계정 삭제 시 함께 제거.

## 인가
- 전 사용자 테이블 RLS `user_id = auth.uid()`. DELETE 정책 없음. `rate_limits`는 service role 전용.
- service role 키는 서버 런타임 환경변수만. 사용처는 `deleteAccount`·`rate_limits` 두 곳으로 한정하고 `lib/supabase/admin.ts`에서만 import(코드 리뷰 grep 대상).

## 입력 검증
- zod 서버 검증 전 액션. 문자열 trim, 길이 상한, 정수 금액. HTML은 저장하지 않고 렌더 시 React 이스케이프.
- 매직링크·쓰기 rate limit(PRD-API공통규약).

## 보안 헤더 (`next.config` headers)
| 헤더 | 값 |
| ---- | ---- |
| Content-Security-Policy | `default-src 'self'; script-src 'self' 'nonce-{nonce}' https://*.posthog.com https://*.sentry.io; connect-src 'self' https://*.supabase.co https://*.posthog.com https://*.sentry.io; img-src 'self' data:; style-src 'self' 'unsafe-inline'; font-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'` — `js` 클래스 인라인 스크립트는 nonce 적용(PRD-디자인시스템 §3.2 규칙 2) |

| X-Content-Type-Options | `nosniff` |
| Referrer-Policy | `strict-origin-when-cross-origin` |
| Permissions-Policy | `camera=(), microphone=(), geolocation=()` |

## 에러 응답
`ActionResult.error`에 code·message·field만. Supabase 에러 원문·스택은 Sentry로만.

## 유출 대응 (사고 시 행동 순서)
1. 증거 보존(Supabase 로그·Vercel 로그 export, 키 즉시 로테이션) → 2. 영향 산정(PII 인벤토리 기준: 이메일 + 소비 행위 데이터, 영향 사용자 수) → 3. **72시간 내 통지·신고**(개인정보보호위원회 신고 + 이용자 이메일 통지, 1천명 미만이어도 통지) → 4. 재발 방지(원인 커밋·정책 수정, EOD 기록).

## 법적 고지
- 개인정보처리방침 `/privacy`: 수집 항목(이메일, 지출 기록), 목적, 보존·파기, 분석 도구(PostHog) 사용, **국외 이전**(Vercel·PostHog·Sentry·SMTP 제공자 — 항목·국가·목적·보존 기간), 이용자 권리(열람·삭제 = SCR-007), 담당자 연락처.
- 이용약관 `/terms`: 서비스 범위, 무료, 계정 삭제, 면책.
- 만 14세 미만: 대상 아님, 가입 시 `over_14` 확인 강제(BR-011). 법정대리인 절차 없음.
- EU: 대상 아님(GDPR 미적용).
- 버전 상수 `TERMS_VERSION`·`PRIVACY_VERSION`(`lib/legal.ts`). 문서 개정 시 상수 상승 → 전 사용자 재동의(BR-011).
