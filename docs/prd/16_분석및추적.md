# 분석 및 추적 (MVP §16 승계)

도구: PostHog(OQ-001 확정 전까지 가정). 전송은 클라이언트 `lib/analytics.ts` 단일 래퍼(`track(evtId, props)`) 경유. `distinct_id` = Supabase user id(이메일 아님).

| EVT-ID | 이벤트명 | 발생 시점 | 속성 (PII 금지) | 측정 지표 | 발화 화면 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| EVT-SESS-001 | app_opened | 인증 레이아웃 마운트(세션당 1회) | screen | H-01 보조 | 전 인증 화면 |
| EVT-TXN-001 | transaction_created | createTransaction 성공 | category_is_watched(bool), via_preset(bool), tap_count(int), duration_ms(int, 화면 진입~성공) | H-01, H-02, H-03 | SCR-002 |
| EVT-FB-001 | feedback_shown | 피드백 한 줄 표시 완료(GSAP onComplete) | category_is_watched, has_prev_month_compare | H-01 | SCR-002 |
| EVT-CAT-001 | watch_toggled | updateCategory(is_watched) 성공 | is_watched, watched_count | H-02 | SCR-004 |
| EVT-SUB-001 | subscription_checkin_submitted | submitCheckin 성공 | used(bool), from_screen("HOME"\|"SUB") | F-007 사용률 | SCR-001, SCR-005 |
| EVT-ACC-001 | account_deleted | deleteAccount 성공 직후(세션 종료 전) | — | 이탈 | SCR-007 |
| EVT-TXN-002 | transaction_edited | updateTransaction 성공 | field_changed[] | 보조 | SCR-003 |
| EVT-TXN-003 | transaction_deleted | deleteTransaction 성공 | — | 보조 | SCR-003 |

- 금액·메모·카테고리 이름·이메일은 속성에 넣지 않는다. `tap_count`는 클라이언트 카운터(포인터다운 이벤트 수), `duration_ms`는 `performance.now()` 차.
- 개인정보처리방침에 분석 도구 사용·국외 이전 고지(PRD-보안및프라이버시).
