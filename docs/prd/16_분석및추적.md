# 분석 및 추적

**외부 분석 도구 없음.** 1인용이라 이벤트 전송 대신 저장된 거래 데이터로 가설을 직접 확인한다(백업 JSON을 열어 계산하거나 화면 숫자로 확인).

| 가설 | 지표 | 산출 방법 (저장 데이터) |
| ---- | ---- | ---- |
| H-01 | 주간 입력일 수 | `txns`의 `date`를 월요일 시작 주로 묶어 서로 다른 날짜 수 |
| H-02 | 감시 대상 주간 건수 변화 | `watched` 카테고리의 주별 `countThisWeek` 추이(홈 카드 "이번 주 n번") |
| H-03 | 입력 소요·탭 수 | **측정 안 함** — 필요해지면 입력 화면에 로컬 기록 추가 |
