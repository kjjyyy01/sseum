# 환경 · 설정 · 배포

## 환경
| 환경 | 호스트 | Supabase | 용도 |
| ---- | ---- | ---- | ---- |
| local | `next dev` | supabase CLI 로컬 | 개발·통합 테스트 |
| preview | Vercel 프리뷰(작업 브랜치) | prod 프로젝트 공유(별도 프로젝트는 무료 플랜 한도상 생략, OQ-006) | 시각 확인·게릴라 테스트 |
| production | Vercel main | prod | 실서비스 |

## 환경변수
| 이름 | 공개 | 환경 |
| ---- | ---- | ---- |
| NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY | 공개 가능 | 전부 |
| SUPABASE_SERVICE_ROLE_KEY | **서버 전용, 번들 금지** | preview·prod(Vercel 암호화 변수) |
| NEXT_PUBLIC_POSTHOG_KEY / NEXT_PUBLIC_POSTHOG_HOST | 공개 가능 | prod만(preview는 계측 off) |
| SENTRY_DSN / NEXT_PUBLIC_SENTRY_DSN / SENTRY_AUTH_TOKEN | DSN 공개 가능, 토큰 서버 전용 | preview·prod |
| NEXT_PUBLIC_APP_URL | 공개 | 전부 (매직링크 redirectTo) |
`.env.example` 커밋, `.env*.local` gitignore. gitleaks 프리커밋(PLAN 보안 5종).

## 렌더링·빌드
- `next build` 시 `/login`·`/terms`·`/privacy`가 Static(○)으로, 인증 라우트가 Dynamic(ƒ)으로 출력되는지 빌드 로그로 확인 — 출시 기준 항목.
- ISR 미사용. `revalidatePath`만.
- GSAP는 Client Component에서만 import. `next/dynamic` 불필요(트리 셰이킹, 코어 ~30KB gz).
- 폰트: `next/font`(Pretendard Variable 로컬 또는 Noto Sans KR) — 디자인시스템 SSOT.

## 배포·롤백
- 작업 브랜치 push → Vercel 프리뷰 자동 → 눈 확인 → main 머지 = 프로덕션.
- 롤백: Vercel 이전 배포 "Promote to Production"(리허설 1회, PLAN §7).
- DB 마이그레이션: `supabase/migrations/*.sql`, `supabase db push` main 머지 전 수동 실행(PRD-마이그레이션).

## 플래그
없음(PRD-실험_피처플래그). 킬 스위치가 필요한 유일 항목 = 분석 계측 → `NEXT_PUBLIC_POSTHOG_KEY` 비우면 래퍼가 no-op.
