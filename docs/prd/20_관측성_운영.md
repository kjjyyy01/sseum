# 관측성 · 운영

| 항목 | 설정 |
| ---- | ---- |
| 에러 트래킹 | 없음. 저장 실패는 화면 문구로 바로 보인다(ERR-STORE-001) |
| 로그 | 없음(서버에 사용자 데이터 없음) |
| 업타임 | Vercel 상태 페이지 |
| 지표 | 저장 데이터로 직접 확인(PRD-분석및추적) |
| 백업 | **사용자 수동** — 설정 → 내보내기. 권장 주기 주 1회, 기기 변경·브라우저 초기화 전 필수 |

## 런북
1. **화면이 안 뜸** — Vercel 상태 → 이전 배포 승격(롤백) → 원인 커밋 revert.
2. **저장이 안 됨(ERR-STORE-001)** — 브라우저 저장 공간·사생활 보호 모드 확인 → 백업 내보내기 → 오래된 데이터 정리.
3. **데이터가 사라짐** — 가장 최근 백업 파일을 설정 → 가져오기.
4. 사후: 트러블슈팅 당일 EOD 기록 + 해결 커밋에 원인·해결 한 줄.
