# 범위 외 (MVP §5 Phase 2 승계)

| 제외 항목 | 이유 | 재검토 조건 |
| ---- | ---- | ---- |
| 결제·과금 | 없음. spec v1.1 결제 도메인 미커버 — 도입 시 별도 결제 스펙 필요 | 유료 플랜 검토 시 |
| Web Push 주간 요약(PWA) | 권한·iOS 홈 화면 장벽 | H-01 통과 후 리텐션 2차 수단으로 |
| CSV/엑셀 업로드·내보내기 | JSON 백업 내보내기·가져오기로 대체(SCR-007) | 스프레드시트 분석이 필요할 때 |
| CODEF 카드사 API | 금융 계정 취급 부담 | 본인 전용 분기 시 |
| 은행·마이데이터 | 개인 불가 | 없음 |
| 결제 문자/알림 파싱 | 웹 불가 | 없음 |
| 예산·자산 관리 | 컨셉 무관 | 없음 |
| 카테고리별 입력 정밀도 차등 | H-03 결과 후 | H-03 미달 시 |
| 로그인·계정(매직링크·소셜) | 1인용, localStorage 저장(2026-09-27) | 다른 사람에게 공개하거나 기기 간 동기화가 필요할 때 |
| 수입 기록 | 컨셉 이탈 | 없음 |
| 관리자 화면 | 1인용 | 없음 |
| 다국어 | 국내 단일 | 해외 타겟 결정 시 |
| 거래 복원(undo) | 하드 삭제, 복원은 백업 파일로만 | 실수 삭제가 반복될 때 |
| 서버 DB·기기 간 동기화 | localStorage로 시작 | 규모를 키울 때 (PRD-마이그레이션 DB 전환 경로) |
| 약관·개인정보처리방침 | 본인 전용 | 외부 공개 시 |
| 외부 분석·에러 트래킹 | 1인용 | 외부 공개 시 |
