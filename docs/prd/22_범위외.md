# 범위 외 (MVP §5 Phase 2 승계)

| 제외 항목 | 이유 | 재검토 조건 |
| ---- | ---- | ---- |
| 결제·과금 | 없음. spec v1.1 결제 도메인 미커버 — 도입 시 별도 결제 스펙 필요 | 유료 플랜 검토 시 |
| Web Push 주간 요약(PWA) | 권한·iOS 홈 화면 장벽 | H-01 통과 후 리텐션 2차 수단으로 |
| CSV/엑셀 업로드·내보내기 | 필요 시 추가 | 사용자 요청 3건 |
| CODEF 카드사 API | 금융 계정 취급 부담 | 본인 전용 분기 시 |
| 은행·마이데이터 | 개인 불가 | 없음 |
| 결제 문자/알림 파싱 | 웹 불가 | 없음 |
| 예산·자산 관리 | 컨셉 무관 | 없음 |
| 카테고리별 입력 정밀도 차등 | H-03 결과 후 | H-03 미달 시 |
| 소셜 로그인 | 매직링크로 충분 | 사용자 요청 |
| 수입 기록 | 컨셉 이탈 | 없음 |
| 관리자 화면 | 1인 운영, Supabase 대시보드로 대체 | 운영 부담 발생 시 |
| 다국어 | 국내 단일 | 해외 타겟 결정 시 |
| 거래 복원(undo) | 소프트 삭제지만 복원 UI 없음 | 실수 삭제 피드백 발생 시 |
