# 마이그레이션

## 저장 형식 버전
| 버전 | 키 | 변경 | 이전 버전에서 올리는 법 |
| ---- | ---- | ---- | ---- |
| 1 | `sseum:v1` | 초기 형식(PRD-데이터모델) | — |

- 형식을 바꿀 때는 새 키(`sseum:v2`)를 쓰고, 첫 읽기에서 `v1`이 있으면 변환해 `v2`에 쓴다. `v1`은 한 배포 동안 남겨 롤백을 허용한 뒤 지운다.
- 백업 JSON의 `version`도 같이 올리고, `importJson`은 이전 버전을 변환해서 받는다.
- 필드 추가는 선택값(없으면 기본값)으로만 — 읽기 쪽이 옛 데이터를 그대로 읽을 수 있어야 한다.

## DB 전환 경로 (규모를 키울 때)
1. v1.0.0 PRD(git `48ef8f8`)의 스키마·RLS·인증을 복원하고 PRD-데이터모델 "DB 전환 매핑"으로 컬럼을 맞춘다.
2. `lib/store.ts`의 함수 안쪽만 Server Action 호출로 바꾼다(이름·인자 유지). 호출부는 `await` 추가.
3. 첫 로그인 시 브라우저에 `sseum:v1`이 있으면 업로드 제안 → 서버에 일괄 저장 → 성공 후 로컬 키 삭제.
4. 백업 JSON 가져오기를 서버 일괄 저장으로 연결(같은 형식 재사용).
