# 반응형 · 브레이크포인트

Tailwind 내장값 단일 기준. 커스텀 브레이크포인트 금지(PLAN 상시 규칙). JS에서 필요하면 `gsap.matchMedia()`에 동일 값을 문자열로 쓰되 값의 출처는 Tailwind 기본값.

| 브레이크포인트 | 범위 | 레이아웃 변형 |
| ---- | ---- | ---- |
| base (mobile) | < 640px | 단일 컬럼, 상단 바(내비 + 입력 FAB, 줄바꿈 허용), 시트는 바텀시트, 컨테이너 패딩 16px |
| sm | ≥ 640px | 단일 컬럼 유지, 컨테이너 max 640px 중앙, 패딩 24px |
| md | ≥ 768px | 대시보드 감시 대상 카드 2열, 내역은 리스트 + 우측 편집 패널(시트 대신) |
| lg | ≥ 1024px | 컨테이너 max: 대시보드·내역 1120 / 입력 760 / 관리·설정 640(PRD-디자인시스템 §1). 상단 바 유지 |

- 최소 지원 뷰포트 360px. 터치 타겟 44×44는 전 브레이크포인트 동일.
- 모션: md 이상에서만 카드 stagger 등장(base는 단일 페이드) — PRD-디자인시스템 §모션.
