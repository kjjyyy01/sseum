## 1. 개요
- **목적:** 감시 대상 지출의 반복 패턴을 최상단에서 보여주고, 월 전체 요약·최근 입력·미신고 구독 체크인을 한 화면에 모은다. 앱의 진입점.
- **구현 기능:** F-004 홈 대시보드, F-007 구독 체크인(카드)
- **렌더링:** `/` 정적 셸 + Client Component. `useDb()`로 저장소를 읽고 `selectHome`(`app/_components/home-dashboard.tsx`)이 v1.0.0 `getDashboard`와 같은 모양으로 계산. 서버 첫 렌더는 빈 화면.

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
| ---- | ---- | ---- | ---- | ---- |
| EL-HOME-001 | 감시 대상 카드 목록 | `WatchCard[]` | Y | `watched[]` 순서 = sort_order. 0개면 EL-HOME-007 대체. 첫 카드 = LCP 요소(가시 시작) |
| EL-HOME-002 | 이번 달 전체 요약 | `SummaryBlock` | Y | month_total, fixed_cost(CPY-HOME-008), top3 |
| EL-HOME-003 | 최근 입력 5건 | 리스트 | Y | 탭 → SCR-003(해당 월) |
| EL-HOME-004 | 입력 FAB | `Fab` | Y | 상단 바 공통. → SCR-002. M-06 |
| EL-HOME-005 | 구독 체크인 카드 | `CheckinCard` | N | `pending_checkins` 비어 있지 않을 때 EL-HOME-001 위에 삽입(BR-008). 항목마다 Y/N 2버튼 |
| EL-HOME-006 | 상단 바 내비게이션 | `AppHeader` | Y | 화면 공통 |
| EL-HOME-007 | 감시 대상 미설정 CTA | 카드 | N | watched 0개: CPY-HOME-003 → SCR-004 |

와이어프레임(모바일): [체크인 카드?] → [감시 대상 카드 ×N (md+ 2열)] → [이번 달 전체 요약] → [최근 입력 5] / 상단 바(내비 + FAB).

## 3. 기능 요구사항
### REQ-HOME-001: 대시보드 로드 (P0)
- **AC-1 (정상):** Given 거래가 있는 상태, When `/` 진입, Then 저장소 값을 `selectHome`으로 계산해 EL-HOME-001·002·003을 렌더한다(M-02 카운트업).
- **AC-2 (검증 실패):** 해당 없음(입력 없음, 항상 이번 달).
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-HOME-002: 구독 체크인 카드 (P1)
- **AC-1 (정상):** Given 이번 달 미응답 해지 안 된 구독 존재, When 진입, Then EL-HOME-005 표시. When Y/N 탭, Then `submitCheckin(id, 이번 달, used)` 성공 → 카드 M-08 퇴장. N이면 토스트로 해지 검토 안내(BR-010).
- **AC-2 (검증 실패):** 해당 없음 — 같은 월에 다시 답하면 덮어쓴다(BR-008). 다른 탭에서 답하면 `storage` 이벤트로 카드가 사라진다.
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-HOME-003: 입력 진입 (P0)
- **AC-1 (정상):** Given Loaded, When EL-HOME-004 탭, Then `/input`으로 이동.
- **AC-2 (검증 실패):** 해당 없음(입력 없음).
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.
