## 1. 개요
- **목적:** 감시 대상 지출의 반복 패턴을 최상단에서 보여주고, 월 전체 요약·최근 입력·미신고 구독 체크인을 한 화면에 모은다. 앱의 진입점.
- **구현 기능:** F-004 홈 대시보드, F-007 구독 체크인(카드)
- **렌더링:** `/` 동적 SSR(Server Component, `getDashboard` rpc 1회). 카드 내부 카운트업·등장 모션과 체크인 버튼만 Client Component.

## 3. 기능 요구사항
### REQ-HOME-001: 대시보드 로드 (P0)
- **AC-1 (정상):** Given 인증·동의 완료 사용자, When `/` 진입, Then `getDashboard(이번 달)` 결과로 EL-HOME-001·002·003이 SSR HTML에 렌더되고 JS 없이도 숫자가 보인다.
- **AC-2 (검증 실패):** Given `?month=` 형식 오류, When 진입, Then 이번 달로 대체(에러 없음).
- **AC-3 (서버 오류):** Given rpc 5xx, When 진입, Then Error 상태(CPY-COMMON-001 + CPY-COMMON-003 버튼). 최근 입력 Suspense는 별도 경계라 성공 시 표시(Partial).
- **AC-4 (오프라인):** Given 오프라인 재방문, When 진입, Then 브라우저 캐시 HTML은 없으므로 브라우저 오류 페이지 대신 앱 `offline` 안내 없음 — 이미 로드된 화면에서 오프라인 전환 시 EL-HOME-008 표시, 버튼 비활성.
- **AC-5 (권한):** Given 세션 없음, When `/` 진입, Then 미들웨어가 302 `/login?next=/` (ERR-AUTH-004). Given 동의 미완료, Then `/login?consent=1` (ERR-AUTH-003).

### REQ-HOME-002: 구독 체크인 카드 (P1)
- **AC-1 (정상):** Given 이번 달 미신고 ACTIVE 구독 존재, When 진입, Then EL-HOME-005 표시. When Y/N 탭, Then `submitCheckin({from_screen:'HOME'})` 성공 → 카드 M-08 퇴장, EVT-SUB-001, 응답 `needs_cancel_review=true`면 토스트 CPY-SUB-003.
- **AC-2 (검증 실패):** Given 같은 월 이미 신고(다른 탭에서), When 탭, Then ERR-SUB-001 → 카드 즉시 제거(이미 처리됨).
- **AC-3 (서버 오류):** Then 버튼 복구 + 토스트 CPY-COMMON-001.
- **AC-4 (오프라인):** Then 버튼 비활성 + ERR-COMMON-002 문구.
- **AC-5 (권한):** Given 타인 subscription_id 조작, When 탭, Then 404 ERR-COMMON-003.

### REQ-HOME-003: 입력 진입 (P0)
- **AC-1 (정상):** Given Loaded, When EL-HOME-004 탭, Then `/input`으로 이동, `performance.now()` 기준 진입 시각을 세션 스토리지에 기록(duration_ms 시작점).
- **AC-2 (검증 실패):** 해당 없음(입력 없음).
- **AC-3 (서버 오류):** Given `/input` 로드 실패, Then SCR-002 Error 상태(이 화면 책임 아님).
- **AC-4 (오프라인):** Then FAB 탭은 허용하되 SCR-002가 Offline 상태로 렌더.
- **AC-5 (권한):** REQ-HOME-001 AC-5와 동일.

## 4. 화면 상태 (Scale=7종)
| 상태 | UI |
| ---- | ---- |
| Loading | 카드 2개·요약·리스트 스켈레톤(Suspense fallback). SSR이라 초기 진입에는 보이지 않고 라우터 전환 시만 |
| Empty | 거래 0건 & 감시 대상 0개: CPY-HOME-001 제목(LCP) + CPY-HOME-002 + EL-HOME-007 + FAB 강조(M-06 back.out) |
| Loaded | EL-HOME-005? → 001 → 002 → 003. M-01·M-02 재생 |

| Offline | 마지막 렌더 유지 + EL-HOME-008. 체크인 버튼 비활성 |
| NoPermission | UI 없음 — 미들웨어 리다이렉트 |
| Partial | 집계 성공·pending_checkins 조회 실패 → EL-HOME-005 생략, 나머지 정상 |

## 6. 화면 전환
- **진입 경로:** `/auth/callback` 성공, 하단 탭 홈, SCR-002 피드백 종료 후 `router.back()` 또는 push(`/`)
- **이탈 경로:** SCR-002/003/004/005/007
- **리다이렉트 규칙:** 세션 없음 → `/login?next=/`; 동의 없음 → `/login?consent=1`
- **뒤로가기/하드웨어 백:** 홈은 스택 루트. 백 → 브라우저 기본(앱 이탈). 로그인 직후 진입 시 히스토리에서 `/login` 제거(`router.replace`)

## 7. 폼 검증 규칙
해당 없음(체크인 버튼은 폼 아님, 값 고정 bool).

## 8. 데이터 변화
- **8.1 생성:** submitCheckin → `subscription_checkins` 1행. 낙관적 업데이트 금지(응답 후 M-08).
- **8.4 조회:** `getDashboard` rpc 1회, 캐시 없음(`dynamic`). `revalidatePath('/')`는 모든 쓰기 액션이 호출.

## 9. API 호출
- **9.1 페이지 로드:** `getDashboard(month)` — Server Component
- **9.2 사용자 액션:** `submitCheckin`
- **9.3 백그라운드:** 없음
- **9.4 응답 처리:** 8s 타임아웃 → Error 상태. 재시도 = `router.refresh()`. 체크인 멱등: UNIQUE

## 13. 비기능
- **성능 예산:** SSR TTFB p95 ≤ 600ms, rpc 단일 쿼리, LCP(첫 WatchCard 또는 Empty 제목) ≤ 2.5s 모바일
- **보안:** RLS(rpc security invoker), 미들웨어 인증·동의 게이트
- **접근성:** 카드는 `<section aria-labelledby>`, 숫자 카운트업 대상에 `aria-live="off"` + 최종값 `aria-label`. 터치 44×44
- **반응형:** md+ 카드 2열, lg+ 사이드 내비(PRD-반응형_브레이크포인트). 모션 M-01·M-02·M-06·M-08
