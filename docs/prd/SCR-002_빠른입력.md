## 1. 개요
- **목적:** 지출 1건을 2~3탭·10초 안에 저장하고, 저장 직후 반복 패턴 피드백 한 줄을 보여준다. 서비스의 핵심 접점(FLOW-001).
- **구현 기능:** F-001 빠른 입력, F-003 즉시 피드백, F-005 프리셋·자동 제안
- **렌더링:** `/input` 정적 셸 + Client Component. `useDb()`로 카테고리(최근 사용순)·프리셋(`derivePresets`)을 계산하고 `createTransaction`으로 저장. 피드백은 저장 직후 `getDb()`로 계산해 M-04 재생.

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
| ---- | ---- | ---- | ---- | ---- |
| EL-INPUT-001 | 프리셋 칩 | `PresetChip[]` | N | presets ≤4(BR-007), 없으면 섹션 숨김. 탭 = 즉시 `createTransaction`. 라벨 CPY-INPUT-007 |
| EL-INPUT-002 | 금액 입력 | `AmountInput` | Y | 자동 포커스, `inputmode="numeric"`, 천 단위 표시. 라벨 CPY-INPUT-001. LCP 요소(가시 시작) |
| EL-INPUT-003 | 카테고리 칩 | `ChipGroup` | Y | 보관 제외, 최근 사용순. 감시 대상 배지. 탭 = 금액이 유효하면 즉시 저장, 아니면 선택만 |
| EL-INPUT-004 | 메모 | Textarea(접힘) | N | CPY-INPUT-009 토글로 펼침, 100자 |
| EL-INPUT-005 | 날짜 | `<input type="date">` | Y | 기본 오늘(Asia/Seoul), `max`=오늘. 접힘 영역(메모와 함께) |
| EL-INPUT-006 | 피드백 한 줄 | `FeedbackLine` | Y | 저장 직후 `getDb()`로 계산한 값으로 M-04. CPY-INPUT-004/005 |
| EL-INPUT-007 | 저장 버튼 | Button | Y | 카테고리 탭이 저장을 트리거하므로 보조. 키보드 Enter 대응 |
| EL-INPUT-008 | 닫기 | 아이콘 버튼 | Y | → 이전 화면 |

와이어프레임: [닫기] / 프리셋 칩 4 / 금액(큰 숫자) / 카테고리 칩 그리드 / [메모 추가 · 날짜] 접힘 / 저장 / (성공 시) 하단 피드백 시트.

**탭 계산(H-03):** 프리셋 경로 = 1탭. 일반 경로 = 금액 입력(키패드 제외 1탭) + 카테고리 1탭 = 2탭. 날짜·메모 변경 시 +1~2.

## 3. 기능 요구사항
### REQ-INPUT-001: 지출 저장 (P0)
- **AC-1 (정상):** Given 금액 8000 입력, When "배달" 칩 탭, Then `createTransaction` → 성공 → `txns` 1건, EL-INPUT-006 표시. 폼은 초기화되고 금액 필드 재포커스(연속 입력).
- **AC-2 (검증 실패):** Given 금액 0 또는 미래 날짜 또는 메모 101자, When 저장, Then 저장하지 않고 ERR-TXN-001/002/004 필드 에러(M-10 + aria-live).
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-INPUT-002: 즉시 피드백 표시 (P0)
- **AC-1 (정상):** Given 저장 성공, Then 저장소에서 이번 주 횟수·이번 달 누적·전월 비교를 계산해 M-04 재생, 문구 = CPY-INPUT-004/005(전월 0건이면 005), 감시 대상이면 `--watch` 강조. 2.5s 후 자동 퇴장 또는 탭 즉시 퇴장.
- **AC-2 (검증 실패):** 해당 없음(저장 후 단계).
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-INPUT-003: 프리셋 원탭 저장 (P1)
- **AC-1 (정상):** Given presets 존재, When 칩 탭, Then 확인 없이 즉시 `createTransaction({ amount, categoryId, date: 오늘, memo: "" })` → REQ-INPUT-002.
- **AC-2 (검증 실패):** 해당 없음 — 보관 카테고리는 프리셋에서 빠진다(BR-007·BR-014).
- **AC-3:** REQ-INPUT-001과 동일. **AC-4/5:** 해당 없음.

### REQ-INPUT-004: 카테고리 자동 제안 (P1)
- **AC-1 (정상):** Given 카테고리 목록, When 렌더, Then 마지막 입력 시각(`createdAt`) 내림차순, 안 쓴 것은 원래 순서로 뒤에, 감시 대상은 배지 표시(순서는 바꾸지 않음).
- **AC-2 (검증 실패):** Given 보관 안 된 카테고리 0개, Then Empty 상태 CPY-INPUT-010 + SCR-004 링크.

## 6. 화면 전환
- **진입 경로:** FAB(상단 바), 딥링크 `/input`
- **이탈 경로:** 닫기 → `/`. 저장 후에는 머무름(연속 입력).
- **리다이렉트 규칙:** 없음(인증 없음)
- **뒤로가기/하드웨어 백:** 입력값 있어도 확인 없이 이탈(입력 부담 최소화, 값은 유실)

## 7. 폼 검증 규칙
| 필드 | 규칙 | 폼 | 저장소 | 에러 |
| ---- | ---- | ---- | ---- | ---- |
| amount | 정수 1~100,000,000 (BR-001) | Y | Y | ERR-TXN-001 |
| categoryId | 보관 안 된 카테고리(칩 목록 안에서만 선택) | Y | — | — |
| date | YYYY-MM-DD, ≤ 오늘 Asia/Seoul (BR-002) | Y(`max`) | Y | ERR-TXN-002 |
| memo | trim ≤100자 (BR-016) | Y | trim | ERR-TXN-004 |

## 8. 데이터 변화
- **생성:** `txns`에 1건 추가(동기). 피드백 값은 저장 후 저장소에서 계산.
- **조회:** 카테고리·프리셋은 `useDb()` 스냅샷에서 매 렌더 계산 — 저장하면 프리셋이 바로 갱신된다.

## 9. API 호출
- **로드:** `useDb()` → 카테고리(최근 사용순), `derivePresets`
- **액션:** `createTransaction`
- **실패:** `false` → 상단 배너(CPY-COMMON-001 / 009) + 입력값 보존 + 다시 시도

## 13. 비기능
- **성능 예산:** 서버 왕복 없음. 저장소 계산은 렌더 안에서 동기 — 입력 경로 Long Task 0
- **보안:** 해당 없음 — 로컬 저장(PRD-보안및프라이버시)
- **접근성:** 금액 필드 `aria-describedby` 오류 연결, 칩은 `role="radio"` 그룹, 피드백 `role="status" aria-live="polite"`
- **반응형:** 칩 그리드 base 3열 / sm 4열 / md 5열. 데스크톱은 카드형 중앙 정렬 max 480
