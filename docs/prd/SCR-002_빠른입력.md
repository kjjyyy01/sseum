## 1. 개요
- **목적:** 지출 1건을 2~3탭·10초 안에 저장하고, 저장 직후 반복 패턴 피드백 한 줄을 보여준다. 서비스의 핵심 접점(FLOW-001).
- **구현 기능:** F-001 빠른 입력, F-003 즉시 피드백, F-005 프리셋·자동 제안
- **렌더링:** `/input` SSR 셸(Server Component가 `getCategories`·`getPresets` 로드 → props) + `InputForm` Client Component + `createTransaction` Server Action. 피드백은 액션 응답으로 받아 클라이언트에서 M-04 재생.

와이어프레임: [닫기] / 프리셋 칩 4 / 금액(큰 숫자) / 카테고리 칩 그리드 / [메모 추가 · 날짜] 접힘 / 저장 / (성공 시) 하단 피드백 시트.

**탭 계산(H-03):** 프리셋 경로 = 1탭. 일반 경로 = 금액 입력(키패드 제외 1탭) + 카테고리 1탭 = 2탭. 날짜·메모 변경 시 +1~2.

## 3. 기능 요구사항
### REQ-INPUT-001: 지출 저장 (P0)
- **AC-1 (정상):** Given 금액 8000 입력, When "배달" 칩 탭, Then `createTransaction` 호출(idempotency_key·tap_count·duration_ms 포함) → 성공 → `transactions` 1행, EL-INPUT-006 표시, EVT-TXN-001. 폼은 초기화되고 금액 필드 재포커스(연속 입력).
- **AC-2 (검증 실패):** Given 금액 0 또는 미래 날짜 또는 메모 101자, When 저장, Then 서버 호출 없이 클라이언트 zod가 ERR-TXN-001/002/004 필드 에러(M-10 + aria-live). 서버에서도 동일 코드 반환 시 같은 표시.
- **AC-3 (서버 오류):** Given 5xx, When 저장, Then ERR-COMMON-001 배너 + 입력값 보존 + 재시도(같은 idempotency_key 재전송).
- **AC-4 (오프라인):** Given offline, When 저장, Then 호출 차단, CPY-COMMON-002, 입력값 보존, 온라인 복귀 이벤트에 버튼 재활성(자동 재전송 없음).
- **AC-5 (권한):** Given 세션 만료, When 저장, Then ERR-AUTH-004 → `/login?next=/input`(입력값 유실 허용). Given 타인·보관 category_id, Then ERR-CAT-004.

### REQ-INPUT-002: 즉시 피드백 표시 (P0)
- **AC-1 (정상):** Given 저장 성공 응답 `feedback`, When 수신, Then M-04 타임라인 재생, 문구 = text_key에 따른 CPY-INPUT-004/005 치환, is_watched면 `--watch` 강조. onComplete → EVT-FB-001. 2.5s 후 자동 퇴장 또는 탭 즉시 퇴장.
- **AC-2 (검증 실패):** 해당 없음(응답 기반).
- **AC-3 (서버 오류):** Given 저장은 성공했으나 feedback null(집계 실패), Then CPY-COMMON-005 토스트로 대체(저장 사실은 알림).
- **AC-4 (오프라인):** 해당 없음(저장 후 단계).
- **AC-5 (권한):** 해당 없음.

### REQ-INPUT-003: 프리셋 원탭 저장 (P1)
- **AC-1 (정상):** Given presets 존재, When 칩 탭, Then 확인 없이 즉시 `createTransaction(amount, category_id, spent_at=오늘, via_preset=true, tap_count=1)` → REQ-INPUT-002.
- **AC-2 (검증 실패):** Given 프리셋 카테고리가 방금 보관됨, Then ERR-CAT-004 → 칩 제거 + 토스트.
- **AC-3/4/5:** REQ-INPUT-001과 동일.

### REQ-INPUT-004: 카테고리 자동 제안 (P1)
- **AC-1 (정상):** Given 카테고리 목록, When 렌더, Then `last_used_at DESC, sort_order` 순, 감시 대상은 배지 표시(순서는 바꾸지 않음).
- **AC-2 (검증 실패):** Given ACTIVE 카테고리 0개, Then Empty 상태 CPY-INPUT-010 + SCR-004 링크.

## 6. 화면 전환
- **진입 경로:** FAB(전 인증 화면), 딥링크 `/input`
- **이탈 경로:** 닫기 → `router.back()`(히스토리 없으면 `/`). 저장 후에는 머무름(연속 입력).
- **리다이렉트 규칙:** 세션·동의 게이트 공통
- **뒤로가기/하드웨어 백:** 입력값 있어도 확인 없이 이탈(입력 부담 최소화, 값은 유실)

## 8. 데이터 변화
- **8.1 생성:** `transactions` INSERT. 낙관적 UI 없음(피드백은 서버 계산 값이라 응답 필수). 중복 탭은 idempotency_key로 1행.
- **8.4 조회:** 카테고리·프리셋 SSR props. 저장 후 `revalidatePath('/')`·`/input`(프리셋 갱신).

## 13. 비기능
- **성능 예산:** 저장 액션 왕복 p95 ≤ 800ms. 탭→피드백 표시 시작 ≤ 1s. 입력 경로 Long Task 0
- **보안:** zod 서버 검증, RLS, rate limit 60/분
- **접근성:** 금액 필드 `aria-describedby` 오류 연결, 칩은 `role="radio"` 그룹, 피드백 `role="status" aria-live="polite"`
- **반응형:** 칩 그리드 base 3열 / sm 4열 / md 5열. 데스크톱은 카드형 중앙 정렬 max 480
