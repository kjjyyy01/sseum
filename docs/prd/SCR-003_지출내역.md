## 1. 개요
- **목적:** 월별 지출을 일자 그룹으로 보고, 항목을 수정·삭제한다.
- **구현 기능:** F-008
- **렌더링:** `/transactions?month=YYYY-MM` 동적 SSR(searchParams). 월 전환은 `router.push`로 서버 재렌더 후 M-05 Flip. 편집 시트만 Client Component.

## 3. 기능 요구사항
### REQ-TXN-001: 월별 조회 (P0)
- **AC-1 (정상):** Given 2026-09 거래 존재, When `/transactions?month=2026-09`, Then 일자 DESC 그룹·소계·합계가 SSR HTML로 렌더.
- **AC-2 (검증 실패):** Given month 형식 오류 또는 미래 월, Then 이번 달로 replace.
- **AC-3 (서버 오류):** Then Error 상태 + 재시도.
- **AC-4 (오프라인):** Given 로드된 화면에서 오프라인, Then 배너, 편집·삭제 비활성, 월 전환 링크는 브라우저 실패.
- **AC-5 (권한):** 세션 없음 → `/login?next=/transactions`.

### REQ-TXN-002: 항목 수정 (P0)
- **AC-1 (정상):** Given 시트에서 금액 변경, When 저장, Then `updateTransaction` → 시트 닫힘, 리스트 재렌더(revalidatePath), 토스트 CPY-COMMON-005, EVT-TXN-002.
- **AC-2 (검증 실패):** SCR-002 §7과 동일 규칙 → ERR-TXN-001/002/004, ERR-CAT-004.
- **AC-3 (서버 오류):** 시트 유지 + 배너 + 재시도.
- **AC-4 (오프라인):** 저장 비활성.
- **AC-5 (권한):** Given 사용자 B의 id, Then 404 ERR-COMMON-003(시트 닫고 토스트 CPY-COMMON-006).

### REQ-TXN-003: 항목 삭제 (P0)
- **AC-1 (정상):** Given 시트, When 지우기 → 확인 탭, Then `deleteTransaction` → status DELETED, 리스트에서 항목 M-08 퇴장, 소계·합계 갱신, EVT-TXN-003.
- **AC-2 (검증 실패):** Given 이미 삭제됨, Then ERR-TXN-003 → 리스트 refresh.
- **AC-3 (서버 오류):** 항목 유지 + 토스트.
- **AC-4 (오프라인):** 삭제 비활성.
- **AC-5 (권한):** 타인 id → 404 ERR-COMMON-003.

## 6. 화면 전환
- **진입 경로:** 하단 탭 내역, SCR-001 최근 항목·감시 카드
- **이탈 경로:** 탭 이동, FAB → SCR-002
- **리다이렉트 규칙:** 공통 게이트, month 정규화 replace
- **뒤로가기/하드웨어 백:** 시트 열림 → 시트 닫기(vaul 기본, 히스토리 push 없음). 월 전환은 히스토리에 남음

## 7. 폼 검증 규칙
SCR-002 §7과 동일(amount·category_id·spent_at·memo). 1개 이상 변경 필수(변경 없으면 저장 버튼 비활성).

## 8. 데이터 변화
- **8.2 수정:** `transactions` UPDATE(updated_at 트리거). 낙관적 없음.
- **8.3 삭제:** 소프트(status DELETED, BR-003). 연쇄 없음. 복원 없음(PRD-범위외).
- **8.4 조회:** `getTransactionsByMonth` 월 단위, 캐시 없음, 2,000행 상한.

## 9. API 호출
- **9.1 페이지 로드:** `getTransactionsByMonth(month)`, `getCategories()`(시트용)
- **9.2 사용자 액션:** `updateTransaction`, `deleteTransaction`
- **9.4 응답 처리:** 8s, 멱등(PATCH/DELETE 자연 멱등)

## 13. 비기능
- **성능 예산:** SSR TTFB p95 ≤ 600ms(인덱스 `(user_id, spent_at)`), 리스트 2,000행 렌더 ≤ 1s
- **보안:** RLS, 타인 404
- **접근성:** 그룹 `<section>` + 날짜 헤딩, 항목 `<button>`, 시트 포커스 트랩
- **반응형:** md+ 시트 대신 우측 패널, 리스트 좌 2/3
