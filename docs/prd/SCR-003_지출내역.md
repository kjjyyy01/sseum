## 1. 개요
- **목적:** 월별 지출을 일자 그룹으로 보고, 항목을 수정·삭제한다.
- **구현 기능:** F-008
- **렌더링:** `/transactions?month=YYYY-MM` — 서버는 month 정규화만(ƒ). 목록·합계·편집은 Client Component(`useDb`). 편집은 md+ 우측 패널, 모바일 vaul 시트.

## 3. 기능 요구사항
### REQ-TXN-001: 월별 조회 (P0)
- **AC-1 (정상):** Given 2026-09 거래 존재, When `/transactions?month=2026-09`, Then 일자 DESC(같은 날은 나중 입력 먼저) 그룹·소계·합계가 렌더.
- **AC-2 (검증 실패):** Given month 형식 오류 또는 미래 월, Then 서버가 이번 달로 redirect.
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-TXN-002: 항목 수정 (P0)
- **AC-1 (정상):** Given 시트에서 금액 변경, When 저장, Then `updateTransaction` → 시트 닫힘, 리스트 재렌더, 토스트 CPY-COMMON-005. 다른 달로 옮기면 행 M-08 퇴장 후 반영(엣지 #1).
- **AC-2 (검증 실패):** SCR-002 §7과 동일 규칙 → ERR-TXN-001/002/004.
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-TXN-003: 항목 삭제 (P0)
- **AC-1 (정상):** Given 시트, When 지우기 → 확인 탭, Then 행 M-08 퇴장 → `deleteTransaction`(하드 삭제, BR-003) → 소계·합계 갱신. 저장 실패면 행 복원 + 토스트 CPY-COMMON-009.
- **AC-2 (검증 실패):** 해당 없음 — 삭제 대상은 화면에 있는 행뿐.
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

## 6. 화면 전환
- **진입 경로:** 상단 바 내역, SCR-001 최근 항목·감시 카드
- **이탈 경로:** 탭 이동, FAB → SCR-002
- **리다이렉트 규칙:** month 형식 오류·미래 월 → 이번 달로 redirect(서버). 인증 게이트 없음
- **뒤로가기/하드웨어 백:** 시트 열림 → 시트 닫기(vaul 기본, 히스토리 push 없음). 월 전환은 히스토리에 남음

## 7. 폼 검증 규칙
SCR-002 §7과 동일(amount·category_id·spent_at·memo). 1개 이상 변경 필수(변경 없으면 저장 버튼 비활성).

## 8. 데이터 변화
- **수정:** `updateTransaction`(동기). 낙관적 갱신 없음 — 다른 달로 옮기면 퇴장 애니메이션 뒤 저장.
- **삭제:** 하드 삭제(BR-003). 복원은 백업 파일로만(PRD-범위외).
- **조회:** `useDb()` 스냅샷에서 해당 월만 필터, 캐시·상한 없음.

## 9. API 호출
- **로드:** `useDb()` → 월 필터·일자 그룹, 카테고리(시트 칩은 보관 제외)
- **액션:** `updateTransaction`, `deleteTransaction`
- **실패:** `false` → 수정은 시트 유지 + 배너(CPY-COMMON-001 / 009), 삭제는 행 복원 + 토스트(CPY-COMMON-009)
