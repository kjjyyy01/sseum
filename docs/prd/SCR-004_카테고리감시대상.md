## 1. 개요
- **목적:** 카테고리를 관리하고 그중 최대 5개를 감시 대상으로 지정한다.
- **구현 기능:** F-002 감시 대상 지정, F-011 카테고리 관리
- **렌더링:** `/categories` 동적 SSR + 토글·인라인 폼 Client Component + Server Action.

| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
| ---- | ---- | ---- | ---- | ---- |

## 3. 기능 요구사항
### REQ-CAT-001: 감시 대상 토글 (P0)
- **AC-1 (정상):** Given 감시 대상 2개, When 토글 on, Then `updateCategory({is_watched:true})` → 응답 watched_count=3, 카운터 갱신, EVT-CAT-001. 토글은 낙관적 전환 허용(실패 시 롤백).
- **AC-2 (검증 실패):** Given 이미 5개, When 6번째 on, Then ERR-CAT-001 → 토글 롤백 + 토스트 CPY-CAT-001. 클라이언트는 5개 도달 시 나머지 토글 disabled로 선제 차단.
- **AC-3 (서버 오류):** 롤백 + CPY-COMMON-001.
- **AC-4 (오프라인):** 토글 disabled + 배너.
- **AC-5 (권한):** 타인 id → 404 ERR-COMMON-003. 세션 없음 → 401 리다이렉트.

### REQ-CAT-002: 카테고리 추가 (P1)
- **AC-1 (정상):** When 이름 입력 후 추가, Then `createCategory` → 리스트 끝에 추가(M-01), 입력 초기화.
- **AC-2 (검증 실패):** 중복 → ERR-CAT-002, 길이 → ERR-CAT-003 (M-10).
- **AC-3/4:** 공통.

### REQ-CAT-003: 이름 변경·보관·복원 (P1)
- **AC-1 (정상):** 이름 변경 → updateCategory(name). 보관 → status ARCHIVED + is_watched=false 강제(BR-014), 보관 섹션으로 이동(Flip). 복원 → ACTIVE.
- **AC-2 (검증 실패):** "기타" 보관 → ERR-CAT-005. 중복 이름 → ERR-CAT-002.
- **AC-3/4/5:** 공통.

## 7. 폼 검증 규칙
| 필드 | 규칙 | 클라 | 서버 | 에러 |
| ---- | ---- | ---- | ---- | ---- |
| name | trim 1~20자, 사용자 내 유일(lower) | Y(길이) | Y(둘 다) | ERR-CAT-003 / ERR-CAT-002 |
| is_watched | bool, on 시 count<5 | Y(disabled) | Y(트랜잭션) | ERR-CAT-001 |
| status | ACTIVE\|ARCHIVED, is_system이면 ARCHIVED 불가 | Y(메뉴 숨김) | Y | ERR-CAT-005 |

## 8. 데이터 변화
- **8.1 생성:** categories INSERT(idempotency_key).
- **8.2 수정:** is_watched(낙관적, 롤백), name, status. 보관 시 is_watched=false 동시 갱신.
- **8.3 삭제:** 없음(보관만). 거래 FK RESTRICT.
- **8.4 조회:** include_archived=true.

## 9. API 호출
- **9.1 페이지 로드:** `getCategories({include_archived:true})`
- **9.2 사용자 액션:** `createCategory`, `updateCategory`
- **9.4 응답 처리:** 8s, 멱등
