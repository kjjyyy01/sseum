## 1. 개요
- **목적:** 카테고리를 관리하고 그중 최대 5개를 감시 대상으로 지정한다.
- **구현 기능:** F-002 감시 대상 지정, F-011 카테고리 관리
- **렌더링:** `/categories` 정적 셸 + Client Component(`useDb`). 토글·인라인 폼이 `createCategory`·`updateCategory`를 동기 호출.

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
| ---- | ---- | ---- | ---- | ---- |
| EL-CAT-001 | 활성 카테고리 리스트 | 리스트 | Y | 이름·감시 토글·더보기(이름 변경·보관). 첫 항목 LCP |
| EL-CAT-002 | 감시 대상 토글 | Switch | Y | 라벨 CPY-CAT-006, 카운터 "n/5" |
| EL-CAT-003 | 카테고리 추가 | 인라인 Input + 버튼 | Y | CPY-CAT-007, 1~20자 |
| EL-CAT-004 | 이름 변경·보관 메뉴 | DropdownMenu | Y | "기타"(is_system)는 보관 항목 없음 |
| EL-CAT-005 | 보관 섹션 | 접힘 리스트 | N | CPY-CAT-004, 복원 버튼 |

## 3. 기능 요구사항
### REQ-CAT-001: 감시 대상 토글 (P0)
- **AC-1 (정상):** Given 감시 대상 2개, When 토글 on, Then `updateCategory(id, { watched: true })` → 카운터 3/5 갱신. 저장 실패 시 상태 불변 + 토스트 CPY-COMMON-009.
- **AC-2 (검증 실패):** Given 이미 5개, When 6번째 on, Then 저장하지 않고 토스트 CPY-CAT-001. 5개 도달 시 나머지 토글은 `aria-disabled`(포커스·안내 유지).
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-CAT-002: 카테고리 추가 (P1)
- **AC-1 (정상):** When 이름 입력 후 추가, Then `createCategory` → "기타" 앞에 추가(M-01), 입력 초기화 + 포커스 유지(연속 추가).
- **AC-2 (검증 실패):** 중복 → ERR-CAT-002, 길이 → ERR-CAT-003 (M-10).
- **AC-3:** 저장 실패 → 입력 아래 오류(CPY-COMMON-009). **AC-4/5:** 해당 없음.

### REQ-CAT-003: 이름 변경·보관·복원 (P1)
- **AC-1 (정상):** 이름 변경 → updateCategory(name). 보관 → archived=true + watched=false 강제(BR-014), 보관 섹션으로 이동(Flip). 복원 → archived=false.
- **AC-2 (검증 실패):** "기타" 보관 → ERR-CAT-005. 중복 이름 → ERR-CAT-002.
- **AC-3:** 저장 실패 → 토스트 CPY-COMMON-009(상태 불변). **AC-4/5:** 해당 없음.

## 7. 폼 검증 규칙
| 필드 | 규칙 | 폼 | 저장소 | 에러 |
| ---- | ---- | ---- | ---- | ---- |
| name | trim 1~20자, 대소문자 무시 유일(보관 포함) | Y | — | ERR-CAT-003 / ERR-CAT-002 |
| watched | bool, on 시 5개 미만 | Y(aria-disabled + 토스트) | — | ERR-CAT-001 |
| archived | system("기타")이면 보관 불가 | Y(메뉴에서 안내) | 보관 시 watched=false 강제 | ERR-CAT-005 |

## 8. 데이터 변화
- **생성:** `categories`에 추가("기타" 앞).
- **수정:** watched·name·archived. 보관 시 watched=false 동시 갱신(저장소가 강제).
- **삭제:** 없음(보관만). 거래는 보관 카테고리를 계속 참조.
- **조회:** `useDb()` 스냅샷 전체(보관 포함) + 이번 달 횟수 계산.

## 9. API 호출
- **로드:** `useDb()` → 이번 달 횟수 포함 목록
- **액션:** `createCategory`, `updateCategory`
- **실패:** `false`/`null` → 상태 불변 + CPY-COMMON-009
