## 1. 개요
- **목적:** 구독을 등록해 고정비를 파악하고, 월 1회 사용 여부를 자기 신고해 해지 검토를 유도한다.
- **구현 기능:** F-006 구독 등록·고정비, F-007 체크인
- **렌더링:** `/subscriptions` 동적 SSR + 추가 시트·체크인 버튼 Client Component. 거래 자동 생성 없음(BR-006).

## 3. 기능 요구사항
### REQ-SUB-001: 구독 등록 (P1)
- **AC-1 (정상):** When 이름·금액·결제일 입력 후 저장, Then `createSubscription` → 리스트 추가(M-01), 고정비 합계 M-02 갱신, 시트 닫힘.
- **AC-2 (검증 실패):** 결제일 0/29 → ERR-SUB-002, 이름 31자 → ERR-SUB-004, 금액 0 → ERR-TXN-001.
- **AC-3 (서버 오류):** 시트 유지 + 배너.
- **AC-4 (오프라인):** 저장 비활성.
- **AC-5 (권한):** 타인 category_id → ERR-CAT-004.

### REQ-SUB-002: 월 체크인 (P1)
- **AC-1 (정상):** When Y 또는 N 탭, Then `submitCheckin({from_screen:'SUB'})` → 항목 상태 "이번 달 사용/미사용", needs_cancel_review면 배지 CPY-SUB-003, EVT-SUB-001.
- **AC-2 (검증 실패):** 중복 → ERR-SUB-001 → refresh.
- **AC-3/4:** 공통.
- **AC-5 (권한):** 타인 subscription_id → 404.

### REQ-SUB-003: 해지 (P1)
- **AC-1 (정상):** When 해지 확인, Then `updateSubscription({status:'CANCELLED'})` → 이력 섹션으로 Flip, 고정비 재계산, 토스트 CPY-SUB-008.
- **AC-2:** 이미 CANCELLED → 무시(멱등).
- **AC-3/4/5:** 공통, 타인 404.

## 8. 데이터 변화
- **8.1 생성:** subscriptions INSERT(idempotency_key); checkins INSERT(UNIQUE).
- **8.2 수정:** status CANCELLED + cancelled_at.
- **8.3 삭제:** 없음(해지 이력 유지).
- **8.4 조회:** getSubscriptions(체크인·배지 계산 포함).
