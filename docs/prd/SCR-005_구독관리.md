## 1. 개요
- **목적:** 구독을 등록해 고정비를 파악하고, 월 1회 사용 여부를 자기 신고해 해지 검토를 유도한다.
- **구현 기능:** F-006 구독 등록·고정비, F-007 체크인
- **렌더링:** `/subscriptions` 정적 셸 + Client Component(`useDb`). 추가 시트(vaul)·체크인·해지가 저장소 함수를 동기 호출. 거래 자동 생성 없음(BR-006).

## 2. 레이아웃 & 구성 요소
| EL-ID | 요소 | 컴포넌트 | 필수 | 조건/참조 |
| ---- | ---- | ---- | ---- | ---- |
| EL-SUB-001 | 구독 리스트 | 리스트 | Y | 이름·금액·결제일·이번 달 체크인 상태·배지(BR-010). 첫 항목 LCP |
| EL-SUB-002 | 추가 시트 | `BottomSheet` + 폼 | Y | 이름·금액·결제일·카테고리(선택) |
| EL-SUB-003 | 체크인 Y/N | 2버튼 | Y | 이번 달 미응답 항목만. CPY-SUB-002 |
| EL-SUB-004 | 해지 | 메뉴 항목 + 인라인 확인 | Y | cancelledAt 기록. 해지 구독은 접힘 이력 섹션(해지 구독이 있으면 빈 상태에서도 표시) |
| EL-SUB-005 | 월 고정비 합계 | 텍스트 | Y | CPY-SUB-007, M-02 |
| EL-SUB-006 | 추가 버튼 | Button | Y | 시트 열기 |

## 3. 기능 요구사항
### REQ-SUB-001: 구독 등록 (P1)
- **AC-1 (정상):** When 이름·금액·결제일 입력 후 저장, Then `createSubscription` → 리스트 추가(M-01), 고정비 합계 M-02 갱신, 시트 닫힘.
- **AC-2 (검증 실패):** 결제일 0/29 → ERR-SUB-002, 이름 31자 → ERR-SUB-004, 금액 0 → ERR-TXN-001.
- **AC-3 (저장 실패):** 조회는 해당 없음(로컬 읽기). 쓰기가 localStorage 예외로 실패하면(ERR-STORE-001) 화면 상태를 유지하고 CPY-COMMON-001 / 009 배너 또는 CPY-COMMON-009 토스트.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장이라 네트워크를 쓰지 않는다.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-SUB-002: 월 체크인 (P1)
- **AC-1 (정상):** When Y 또는 N 탭, Then `submitCheckin(id, 이번 달, used)` → 항목 상태 "이번 달 사용/미사용", 해지 검토(BR-010)면 배지 CPY-SUB-003.
- **AC-2 (검증 실패):** 해당 없음 — 같은 월에 다시 답하면 덮어쓴다(BR-008).
- **AC-3:** 저장 실패 → 토스트 CPY-COMMON-009. **AC-4:** 해당 없음.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-SUB-003: 해지 (P1)
- **AC-1 (정상):** When 해지 확인, Then `cancelSubscription(id, 이번 달)` → 이력 섹션으로 Flip, 고정비 재계산, 토스트 CPY-SUB-008.
- **AC-2:** 해당 없음 — 해지된 구독엔 메뉴가 없다.
- **AC-3:** 저장 실패 → 토스트 CPY-COMMON-009(Flip 취소). **AC-4/5:** 해당 없음.

## 8. 데이터 변화
- **생성:** `subs`에 추가, 체크인은 (구독, 월) 1개(덮어씀).
- **수정:** 해지 = `cancelledAt` 기록.
- **삭제:** 없음(해지 이력 유지).
- **조회:** `useDb()` 스냅샷에서 이번 달·직전 달 체크인과 해지 검토(BR-010) 계산.

## 9. API 호출
- **로드:** `useDb()` → checkinOf·fixedCost
- **액션:** `createSubscription`, `submitCheckin`, `cancelSubscription`
- **실패:** `false` → 시트 유지 + 배너(추가) / 토스트 CPY-COMMON-009(체크인·해지)
