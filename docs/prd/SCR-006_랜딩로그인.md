## 1. 개요
- **목적:** 유일한 공개 페이지. 서비스를 3줄로 소개하고 이메일 매직링크로 로그인·가입시키며, 첫 로그인 시 동의를 기록한다.
- **구현 기능:** F-009 회원 인증(+동의)
- **렌더링:** `/login` **SSG**(`generateMetadata`·OG). 이메일 폼·동의 폼만 Client Component. `?consent=1`·`?next=`·`?deleted=1`는 클라이언트에서 `useSearchParams`로 읽음(정적 유지). 이미 로그인된 사용자는 미들웨어가 `/`로.

## 3. 기능 요구사항
### REQ-LOGIN-001: 매직링크 발송 (P0)
- **AC-1 (정상):** Given 유효 이메일, When 발송, Then `sendMagicLink({email, next})` → Supabase `signInWithOtp(redirectTo=/auth/callback?next=)` → EL-LOGIN-004 표시. 링크 클릭 → `/auth/callback` 코드 교환 → 시드 카테고리 생성(최초, BR-017) → 동의 확인 → `/` 또는 `/login?consent=1`.
- **AC-2 (검증 실패):** 형식 오류 → ERR-AUTH-005(M-10). 5분 3회 초과 → ERR-AUTH-002(CPY-LOGIN-005).
- **AC-3 (서버 오류):** SMTP 실패 → ERR-AUTH-001(CPY-LOGIN-006) + 재시도.
- **AC-4 (오프라인):** 버튼 비활성 + CPY-COMMON-002.
- **AC-5 (권한):** 이미 로그인 → 미들웨어 `/`로. 콜백 code 무효·만료 → `/login?error=expired` 배너(CPY-LOGIN-006 재사용).

### REQ-LOGIN-002: 동의 기록 (P0)
- **AC-1 (정상):** Given `?consent=1` + 세션, When 체크 후 계속, Then `recordConsent({terms_version, privacy_version, over_14:true})` → consents 1행 → `next` 또는 `/`.
- **AC-2 (검증 실패):** 미체크 → ERR-AUTH-006(CPY-LOGIN-009). 버전 불일치(약관 개정 중) → 서버가 현재 상수로 저장(클라 값 무시).
- **AC-3 (서버 오류):** 배너 + 재시도.
- **AC-4 (오프라인):** 비활성.
- **AC-5 (권한):** 세션 없이 recordConsent → ERR-AUTH-004 → 이메일 폼 모드로.

## 6. 화면 전환
- **진입 경로:** 직접, 미들웨어 리다이렉트(`next`), 계정 삭제 후(`deleted=1`), 로그아웃 후
- **이탈 경로:** 콜백 → `/` 또는 `next`
- **리다이렉트 규칙:** 세션 있음 & 동의 있음 → `/`; 세션 있음 & 동의 없음 & consent 파라미터 없음 → `?consent=1`
- **뒤로가기/하드웨어 백:** Sent → 폼으로(클라 상태). 콜백 이후 `/login`은 히스토리에서 replace

## 7. 폼 검증 규칙
| 필드 | 규칙 | 클라 | 서버 | 에러 |
| ---- | ---- | ---- | ---- | ---- |
| email | RFC 형식, trim, lower, ≤254 | Y | Y | ERR-AUTH-005 |
| consent(체크박스) | true 필수 | Y | Y(over_14=true CHECK) | ERR-AUTH-006 |
| next | 같은 오리진 상대경로만(`/`로 시작, `//` 금지) | — | Y | 무시 후 `/` |

- **8.4 조회:** 없음(정적).

- **9.4 응답 처리:** 발송 rate limit(BR-013); 콜백 실패 → `?error=expired`

## 13. 비기능
- **성능 예산:** Lighthouse 모바일 ≥ 90, LCP(H1) ≤ 2.5s, 정적 HTML ≤ 50KB, GSAP 청크는 히어로 하이드레이션 후
- **보안:** redirectTo 화이트리스트, next 검증, 매직링크 1회용 1h, CSP nonce
- **접근성:** H1 SplitText 시 `aria-label` 원문, 폼 라벨, 오류 aria-live
- **반응형:** 히어로 base 40/48 → lg 56/64. OG 이미지 1200×630
- **SEO:** `generateMetadata` title/description/OG, `robots` index. 인증 라우트는 `noindex`
