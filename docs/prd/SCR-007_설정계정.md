> 2026-09-27 변경: 계정·로그아웃이 사라져 "설정·계정"에서 **설정·데이터**로 바뀌었다. F-010(계정 삭제)은 "모든 데이터 지우기"로 대체. 파일명은 ID 안정성을 위해 유지.

## 1. 개요
- **목적:** 저장 현황 요약, 카테고리·구독 관리 진입, 백업 내보내기·가져오기, 모든 데이터 지우기.
- **구현 기능:** F-010(대체: 전체 삭제) + 백업
- **렌더링:** `/settings` 정적 셸 + Client Component(`useDb`). 지우기 시트는 vaul.

## 3. 기능 요구사항
### REQ-SET-001: 모든 데이터 지우기 (P0)
- **AC-1 (정상):** Given 시트에 `삭제` 입력, When 모두 지우기, Then `clearAll()` → 저장 키 삭제 → 시트 닫힘 → 토스트 CPY-SET-011 → 화면이 시드 상태(기록 0건, 카테고리 7개)로 재렌더.
- **AC-2 (검증 실패):** 확인어 불일치 → ERR-CLEAR-001(CPY-SET-003) + M-10 흔들기 + 입력 포커스. 실행 버튼은 `aria-disabled`라 눌러서 문구를 받을 수 있다.
- **AC-3 (저장 실패):** 키 삭제 예외 → 시트 유지 + CPY-COMMON-009.
- **AC-4 (오프라인):** 해당 없음 — 로컬 저장.
- **AC-5 (권한):** 해당 없음 — 1인용, 인증 없음.

### REQ-SET-002: 백업 내보내기·가져오기 (P0)
- **AC-1 (정상):** When 내보내기, Then `sseum-backup-YYYY-MM-DD.json` 다운로드(`exportJson()`). When 가져오기 → 파일 선택, Then 확인 바 → 바꾸기 → `importJson()` → 토스트 CPY-SET-009, 화면 재렌더.
- **AC-2 (검증 실패):** JSON이 아니거나 형식 불일치 → ERR-BACKUP-001(CPY-SET-010), 현재 데이터 불변.
- **AC-3 (저장 실패):** 쓰기 예외도 `importJson`이 `false`를 돌려 CPY-SET-010이 뜬다(현재 데이터 불변). ponytail: 형식 오류와 저장 실패를 구분하지 않음 — 헷갈리면 ERR-STORE-001로 분리.
- **AC-4 / AC-5:** 해당 없음.

## 8. 데이터 변화
- **삭제:** 키 `sseum:v1` 제거 → 다음 읽기에서 시드. 되돌릴 수 없음(BR-012).
- **가져오기:** 현재 데이터를 백업으로 통째로 교체(BR-018). 병합 없음.

## 9. API 호출

- **액션:** `exportJson`, `importJson`, `clearAll`
